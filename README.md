# 🔍 VLESS IP Scanner

Скрипт для анализа подсетей из VLESS-ключей: загрузка по ссылке или из файла → пинг → whois → отчёт.

## 📋 Возможности

- ✅ Мульти-загрузка проверенных RU-источников (с автоматическим fallback и зеркалами при недоступности)
- ✅ Загрузка ключей по любой пользовательской прямой ссылке
- ✅ Загрузка ключей из скачанного файла (локальный `.txt`, `.conf`, `.json`)
- ✅ Автоматическое декодирование подписок и файлов в формате Base64
- ✅ Извлечение уникальных IP из VLESS-ссылок (и списков IP)
- ✅ Проверка доступности хостов через ping
- ✅ Запрос whois только для ответивших узлов
- ✅ Умный парсинг: фильтрация регистраторов (RIPE/ARIN/APNIC)
- ✅ Поиск подсетей по ASN и авто-определение ASN по IP
- ✅ Красивый отчёт в терминале + экспорт в CSV и Mermaid-граф для Obsidian MD
- ✅ Пошаговое управление VPN (для локального файла шаг загрузки через VPN пропускается)

## 🛠 Требования

```bash
# Debian/Ubuntu/Astra Linux
sudo apt install bash curl grep iputils-ping whois awk sed

# Alpine Linux
apk add curl grep iputils ping whois gawk sed
```

## 🚀 Быстрый запуск

```bash
# 1. Скачайте скрипт
curl -O https://raw.githubusercontent.com/wubery/Glaz_gora/main/auto_scan.sh
chmod +x auto_scan.sh

# 2. Мульти-загрузка всех RU-источников (с fallback):
./auto_scan.sh -d
# или
./auto_scan.sh --all

# 3. Запуск с конкретной ссылкой:
./auto_scan.sh "https://raw.githubusercontent.com/zieng2/wl/main/vless_universal.txt"
# или с флагом:
./auto_scan.sh --url "https://..."

# 4. Запуск со скачанным файлом ключей:
./auto_scan.sh keys.txt
# или с флагом:
./auto_scan.sh --file /path/to/downloaded_keys.txt
```

## 🌐 Источники с RU-серверами по умолчанию

По умолчанию скрипт опрашивает набор репозиториев с российскими серверами и обходами блокировок:
- 🇷🇺 **zieng2/wl**: `vless_universal.txt` — универсальный whitelist-набор
- 🇷🇺 **igareck/vpn-configs-for-russia**:
  - `BLACK_VLESS_RUS.txt` — полный набор проверенных VLESS
  - `BLACK_VLESS_RUS_mobile.txt` — конфигурации для мобильных сетей
  - `Vless-Reality-White-Lists-Rus-Mobile.txt` — Vless-Reality для белых списков
  - `BLACK_SS+All_RUS.txt` — Shadowsocks, Hysteria2 и VMess
  - `WHITE-CIDR-RU-all.txt` — белые списки CIDR
  - *(поддерживается автоматическое переключение на зеркало GitLab при блокировке GitHub)*
- 🇷🇺 **NiREvil/vless**: `sub/country_proxies/RU.txt` — база прокси РФ

> 💡 **Отказоустойчивость (Fallback)**: если какой-либо из репозиториев не отвечает, временно заблокирован или выдает ошибку, скрипт автоматически переходит к следующему, объединяя все полученные ключи и исключая дубликаты.

## ⚙️ Настройка источников

Вы можете изменить или дополнить список источников:
1. **Через файл конфигурации `auto_scan.conf`** (скрыт в `.gitignore`):
   ```bash
   cp auto_scan.conf.example auto_scan.conf
   # отредактируйте DEFAULT_SOURCES в auto_scan.conf
   ```
2. **Через переменную окружения**:
   ```bash
   export VLESS_SOURCES="https://ссылка-1... https://ссылка-2..."
   ./auto_scan.sh -d
   ```

## 🔄 Интерактивный режим

Если запустить скрипт без аргументов, откроется главное меню:
```bash
./auto_scan.sh
```

При выборе пункта `1) Сканировать VLESS`:
1. Нажмите **Enter** — скрипт автоматически загрузит все проверенные RU-источники с fallback;
2. Выберите `2` — для указания локального скачанного файла с ключами;
3. Выберите `3` — для ввода своей отдельной ссылки на подписку.

## 🔐 Алгоритм работы с VPN

Скрипт пошагово управляет состоянием сети:
1. 🔐 **Включите VPN** → загрузка ключей по ссылке (при использовании локального файла шаг автоматически пропускается)
2. 🔓 **Выключите VPN** → точный ping и whois без искажений от прокси
3. 🔐 **Включите VPN** → whois-запросы (если заблокированы у провайдера) и вывод отчёта

> 💡 Это позволяет избежать блокировок при загрузке и получить корректные whois-данные.

## 🧩 Формат входных данных

Скрипт принимает и автоматически парсит любые современные протоколы и форматы:
1. **Все популярные протоколы прокси**:
   - `vless://uuid@HOST:PORT?...#comment`
   - `vmess://BASE64` (авто-декодирование JSON и извлечение хоста из `"add"`)
   - `trojan://password@HOST:PORT?...#comment`
   - `ss://BASE64@HOST:PORT#comment` или `ss://BASE64#comment` (Shadowsocks SIP002)
   - `hysteria2://auth@HOST:PORT?...` и `hy2://...`
   - `tuic://auth@HOST:PORT?...`
2. **Доменные имена и DNS-резолв**:
   - Скрипт принимает как прямые IPv4, так и доменные имена (`sub.example.com`).
   - Все доменные имена автоматически разрешаются в IPv4 через системный DNS/`nslookup`/`ping`.
3. **Base64-подписки**:
   - Зашифрованные Base64-подписки (как единым блоком, так и построчно) определяются и расшифровываются автоматически.
4. **Списки IP-адресов**:
   - Текстовые списки с форматами: `IP PORT`, `IP:PORT` или чистый `IP`.
5. **Фильтрация заглушек**:
   - Немаршрутизируемые адреса (`0.0.0.0`, `127.*`, `255.255.255.255`) и сервисные домены исключаются автоматически.
6. **Автоматическая нормализация ссылок GitHub**:
   - Ссылки вида `https://github.com/user/repo/blob/main/file.txt` автоматически конвертируются в `raw.githubusercontent.com`.

## ⚠️ Ограничения

- `whois` имеет лимиты на частоту запросов — скрипт добавляет `sleep 0.1` между запросами
- Для >100 подсетей выполнение может занять 1–2 минуты
- Некоторые IP могут вернуть `Legacy/Unassigned`, если диапазон не делегирован провайдеру
